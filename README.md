# GreenLeaf Café

**Fresh Coffee. Fresh Ideas.**

A modern, responsive website for GreenLeaf Café — a fictional, premium, eco-friendly café based in Indiranagar, Bengaluru. This project was created for learning purposes as part of an internship assignment exploring **AI-powered website generation**, using an AI assistant (Claude) as a development aid alongside manual review and customization.

---

## 📖 Description

GreenLeaf Café is a fictional café brand built to demonstrate a complete, production-style front-end website: a hero section, an about story, a filterable menu, a "why choose us" section, a gallery, special offers, and a working contact/newsletter flow — all built with plain HTML, CSS, and JavaScript, with no frameworks or build tools.

---

## ✨ Features

- 📱 Fully responsive design (desktop, tablet, mobile)
- 🌗 Dark mode toggle (preference saved with `localStorage`)
- 📌 Sticky navigation with scroll-based active-link highlighting
- 🎬 Scroll-triggered reveal animations (`IntersectionObserver`)
- ☕ Menu filtering by category (Coffee / Tea / Desserts / Healthy Food)
- ✉️ Working front-end contact form (with confirmation message)
- 📰 Newsletter subscription form (with confirmation message)
- 🖼️ Responsive image gallery with hover-zoom effect
- ⬆️ Floating back-to-top button
- 📊 Animated statistic counters
- 🍃 Branded loading screen and favicon
- 🎯 Smooth scrolling and button ripple effects

---

## 🛠️ Technologies Used

- **HTML5** — semantic page structure
- **CSS3** — custom design system, Flexbox/Grid layout, animations, responsive media queries
- **JavaScript (Vanilla)** — no frameworks or libraries

## 🚀 Getting Started

No installation or build step is required.

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.

---

## 🌐 Deployment (GitHub Pages)

1. Push the project files to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit — GreenLeaf Café website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/greenleaf-cafe.git
   git push -u origin main
   ```
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select the **main** branch and **/ (root)** folder, then click **Save**.
5. After a minute or two, the site will be live at:
   ```
   https://<your-username>.github.io/greenleaf-cafe/
   ```
